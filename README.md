# AI_Agent_usingOLLAMA

An intelligent AI-powered research assistant built using LangChain, Ollama, and Python.
This project can search, analyze, and generate structured research reports by leveraging external tools like search APIs and powerful LLMs.

🚀 Features

🤖 AI Agent Powered by LangChain – Uses ChatOllama to process queries intelligently.

🔎 Search Tool Integration – Fetches real-time data for more accurate research.

📊 Structured Output with Pydantic – Generates well-defined, validated JSON responses.

📝 Research Paper Generation – Summarizes information into a report format with topic, summary, sources, and tools used.
